# note 記事生成プロンプト（おつまみごろー）

## 記事テーマ
[[ARTICLE_THEME]]

## 構成
1. 導入（300文字）- 読者の悩みに共感、この記事で解決できることを宣言
2. 本文 - 各アイテム/レシピの紹介（使用感・評価・実際に作った感想）
3. まとめ - ベスト3の再提示、次回予告

## ルール
- 無料プレビュー: 全体の30%（導入 + 上位3位まで）
- 有料パート: 残り70%（詳細レビュー + レシピ + 比較表 + 裏技）
- 文体: 友達に話す感じ、でも情報は具体的に
- グッズには価格・ブランド・購入場所を必ず明記
- レシピには材料・手順・所要時間を明記
- 冒頭に Threads アカウントへの誘導リンクを入れる
